Avalon —— 本地 AI 个人助手

面向个人的轻量智能助手，采用 Tauri 2（Rust 后端 + React 19 前端）构建， 具备多轮对话、会话记忆、定时任务、渠道对接四大核心能力，并内置本地向量化模型，无需额外部署服务即可开箱即用。 独立完成需求分析 → 框架设计 → 原型设计 → 开发 → 测试 → 部署打包全流程。

多轮对话

ReAct 引擎驱动，流式输出，工具调用与中间推理过程可视化

会话记忆

自动压缩 + 渐进式总结 + 向量检索（semantic / keyword / hybrid 三模式）

渠道对接

飞书长连接，私聊直聊、群聊 @ 触发；tokio-tungstenite + prost 手写私有协议

定时任务

once / daily / weekly 灵活调度，执行历史可继续追问，未读角标提醒

灵魂与技能

用户画像与自我设定的长期记忆管理，工具技能可插拔扩展

用量与零成本

本地 embedding（candle · bge-small-zh-v1.5）向量化零 API 成本，token 按「天 × 模型」聚合可视化

毕业设计

《基于 LLM 的强化记忆检索和自定义工作流的个人智能体助手》

系统分为智能体核心、记忆系统、工具生态、定时任务、多平台接入五大部分； 难点在于长期记忆的向量检索与衰减压缩策略、多工具调用的编排与错误恢复、跨会话的用户画像沉淀机制。
